# Phase-resolved trajectory analysis

Written for: you, and anyone reading the project record. Companion to
`FULL_ACCOUNT.md`, which establishes *that* contact-aware demonstrations are
harder to learn from. This document asks **where in the task** that happens.

Data: `data/v4_still`, AnyTeleop held fixed, successful episodes only —
41 baseline against 56 contact-aware, 8–17 per (object, condition) cell.
Generated by `scripts/plot_phases.py` and `scripts/plot_phase_grid.py`.

---

## 1. Summary

The headline result said contact-aware data trains policies 3–10× worse. The
phase decomposition says that number is an average over three regimes that
behave differently, and one of them runs the other way:

| Phase | baseline | contact-aware | ratio | Cohen d | p |
|---|---|---|---|---|---|
| APPROACH | 6.82 cm | 9.92 cm | **1.45× worse** | −0.74 | 0.00016 |
| **PICK** | 13.79 cm | 6.55 cm | **0.47× BETTER** | +1.33 | < 0.00001 |
| TRANSPORT | 12.44 cm | 11.35 cm | 0.91× | +0.22 | 0.29 (ns) |

*(Per-episode mean deviation from the condition's own mean path, pooled over
objects. n = 41 / 56.)*

**The certificate halves the variability of the grasp itself and raises it by
~45% on the approach to the grasp.** TRANSPORT is a wash. So "contact-aware
demonstrations are more variable" is false as a blanket statement — the effect
is localised, signed, and reverses at the moment the certificate acts.

The large effect is the *good* one: PICK at d = +1.33 is a stronger result in
contact-aware's favour than APPROACH's d = −0.74 is against it.

---

## 2. Method

### What a "phase" is here

TASK phases — `APPROACH`, `PICK`, `TRANSPORT`, `PLACE` — stored per row in each
episode `.npz`. These are reconstructed from the **event stream**, not read from
the trace's `phase` column: that column omits PICK for every baseline mode, so
reading it would have made 41 of 97 episodes appear to skip the grasp entirely
(`logs.phase_per_row`). Verified: 0 of 97 episodes missing PICK.

These are **not** the controller phases (`PLAN` / `REACH` / `GRASP`) that
`plot_trajectories.py` colours by. Task phase says what the operator is doing;
controller phase says who is driving. They do not align, and conflating them
would be a mistake — the APPROACH divergence below contains both operator
motion and planner replay.

`PLACE` is excluded throughout: it is ~1 row per episode, a terminal marker
rather than a segment.

### Extracting a phase segment

For each episode and phase, the **longest contiguous run** of that label. Not
every matching row: a failed pick can re-enter APPROACH, and stitching disjoint
runs together would draw a line through space the arm never travelled. Runs
shorter than 5 rows are dropped.

### Normalisation, and why

Each segment is resampled to a fixed number of points on [0, 1] *within the
phase*. Two consequences worth stating:

- A 7 s baseline APPROACH and a 24 s contact-aware APPROACH become comparable,
  so the figures show **path shape, not duration**.
- Duration is therefore a separate question, answered in §5 rather than
  conflated here. Without this, "contact-aware is different" would be
  unfalsifiable — it takes longer, so of course its raw time series differs.

### The spread statistic

Two related quantities appear below; they answer different questions.

**Cross-episode spread at a point** — at each normalised time index, the
standard deviation across episodes of palm position, taken as the Euclidean
norm of the per-axis sds. This is what the figures plot. It is a property of
the *set* of demonstrations.

**Per-episode deviation** — for each episode, its mean distance from the
condition's own mean path. This gives one number per episode, so it supports a
t-test across episodes. That is what §1's table reports.

The second is the defensible one for a significance claim: the first has no
natural n, since the points along a resampled curve are not independent.

## 3. The main finding, per object

The pooled numbers hide that the PICK reversal holds on **every object**:

| Object | APPROACH | PICK | TRANSPORT |
|---|---|---|---|
| wood block | 1.35× worse | **0.32× better** | 0.83× better |
| gelatin box | 1.74× worse | **0.35× better** | 0.75× better |
| orange | 1.78× worse | **0.57× better** | 1.03× |
| mug | 1.63× worse | **0.62× better** | 1.03× |

*(Mean cross-episode spread, contact-aware ÷ baseline.)*

Four of four on PICK, ranging 0.32–0.62×. Four of four on APPROACH, ranging
1.35–1.78×. The sign is not object-dependent; only the magnitude is.

**The ordering is interpretable.** The wood block and gelatin box — the two
box-shaped objects, where a certified antipodal grasp is most constrained —
show the largest PICK improvement (0.32×, 0.35×). The orange (a sphere, where
any diameter works) and the mug (where the handle makes a canonical grasp
ill-defined) show the smallest (0.57×, 0.62×). That is what you would predict
if the certificate's value is *removing choice* where choice exists.

## 4. The mechanism: an arch, not a drift

The z-against-progress view shows what the 3D paths hide. During APPROACH,
contact-aware **lifts the palm and brings it back down**; baseline descends
toward the object more directly.

| Object | baseline z: start → peak @ % → end | contact-aware | arch height |
|---|---|---|---|
| wood block | 1.180 → 1.237 @ 30% → 1.125 | 1.180 → 1.263 @ 22% → 1.172 | **+8.3 cm** |
| gelatin box | 1.180 → 1.196 @ 16% → 0.964 | 1.180 → 1.374 @ 50% → 0.968 | **+19.4 cm** |
| orange | 1.180 → 1.202 @ 16% → 0.985 | 1.180 → 1.268 @ 82% → 1.010 | **+8.8 cm** |
| mug | 1.180 → 1.234 @ 18% → 1.016 | 1.180 → 1.259 @ 36% → 1.043 | **+7.9 cm** |

*(Mean curve. Every episode starts at the same home pose, hence the identical
1.180 m start.)*

The gelatin box is the extreme case: a 19.4 cm rise peaking at the exact
midpoint of the phase, then a descent to within 4 mm of where baseline ends.
Same destination, a very different route.

This is the certificate's pregrasp standoff — it plans an approach from above
rather than in-plane, which is sensible for a multi-finger grasp and is where
the APPROACH variability lives. The peak timing varies a lot by object (22% to
82% of the phase), and that variation is itself part of the inconsistency.

## 5. Convergence at the commit point

The clearest single result in this analysis. Cross-episode spread at the **last
frame** of APPROACH — the moment the grasp is committed:

| Object | baseline | contact-aware | |
|---|---|---|---|
| wood block | 9.9 cm | **3.3 cm** | 3.0× tighter |
| gelatin box | 9.8 cm | **3.1 cm** | 3.2× tighter |
| orange | 10.5 cm | **5.3 cm** | 2.0× tighter |
| mug | 11.1 cm | **7.1 cm** | 1.6× tighter |

Every contact-aware episode arrives at nearly the same committed pose. That is
the certificate working exactly as designed, and it is measurable.

Then it reverses. By the **end of TRANSPORT**:

| Object | baseline | contact-aware |
|---|---|---|
| wood block | 13.6 cm | 18.6 cm |
| gelatin box | 9.9 cm | 15.9 cm |
| orange | 12.4 cm | 16.9 cm |
| mug | 14.4 cm | 16.4 cm |

Wider on all four.

**So the structure across an episode is: diverge, converge hard at the grasp,
diverge again.** The one moment the certificate controls is the one moment the
demonstrations agree, and the agreement does not propagate in either direction.

## 6. Where the time goes

Separate from path shape, and a finding in its own right.

| | APPROACH | PICK | TRANSPORT |
|---|---|---|---|
| baseline, share of rows | 28% | 31% | 38% |
| contact-aware, share of rows | **53%** | 21% | 25% |

Absolute durations make the reason plain: baseline's APPROACH is a tight box
around ~7 s; contact-aware's has a median of ~24 s with a box spanning
**10–49 s** and a whisker to 87 s.

That is the solver wait — and its *variance*, not its length, is what a
Markovian policy cannot model. Two episodes at the same observation may be 10 s
or 49 s from the commit, with nothing in the 78-D observation to distinguish
them.

Note this is already partly mitigated in `v4_still`: `collapse_still` removed
94.6% of stationary PLAN rows. The durations above are what *survives* that
filter, i.e. real motion.

## 7. What this changes

**It refines the headline claim.** "Contact-aware demonstrations are more
variable" is wrong as stated. The accurate version: *the certificate halves
grasp variability and raises approach variability, and the net effect on a
policy that must learn the whole episode is negative.*

**It identifies a cheap intervention.** The divergence is in the approach *to*
a converged target. If the arch is the cause, constraining the approach path —
a fixed standoff height, or a smoothed/deterministic plan to the pregrasp —
should reduce APPROACH variability while preserving the PICK convergence that
already works. That is a more targeted next experiment than the
deterministic-planner arm I previously proposed, and it follows from the data
rather than from a hypothesis about RRT.

**It explains the arm/hand loss split.** The per-block result (arm 17.2× vs
hand 7.0×) and the phase result say the same thing from different directions:
the fingers at the grasp are fine, the arm getting there is not.

---

## 8. Limitations

- **Palm position only.** Orientation, joint configuration and finger state are
  not in these numbers. Two episodes with identical palm paths can differ in
  wrist roll.
- **Cartesian spread is not the learnability metric.** On the wood block the
  pooled palm-spread ratio is 1.04× while the loss gap is 3.4×. These figures
  show *where* episodes differ; the loss and action-divergence numbers are what
  establish that it matters.
- **TRANSPORT is not significant** (p = 0.29). Reporting it as 0.91× would
  overstate it; it is a null.
- **Unequal n** (41 vs 56). Welch's t-test does not assume equal variance or
  size, but the contact-aware cells are better populated and the wood-block
  baseline cell is the smallest at n = 8.
- **Successful episodes only.** Failures are excluded by the extraction, so
  this says nothing about what divergence looks like when the task fails.
- **Phase boundaries come from the event stream**, which depends on
  `hand-control`'s own trigger logic. The APPROACH→PICK transition in
  particular has no physical correlate in baseline modes — it advances on a
  physical-pick trigger rather than an operator action.

## 9. Reproducing

```bash
# the three single-figure views
uv run python scripts/plot_phases.py --data data/v4_still --view spread
uv run python scripts/plot_phases.py --data data/v4_still --view budget
uv run python scripts/plot_phases.py --data data/v4_still --view overlay

# object x phase grids
uv run python scripts/plot_phase_grid.py --mode 3d
uv run python scripts/plot_phase_grid.py --mode time --axis z
uv run python scripts/plot_phase_grid.py --mode time          # all three axes
```

Figures land in `docs/figs/`. Both scripts accept `--data` to point at any
extracted dataset and `--retargeter` to change the held-fixed factor.
